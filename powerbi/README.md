# Power BI File

Place your `.pbix` file in this folder (e.g., `Walmart_Retention_Dashboard.pbix`).

It wasn't included in this export — if you have the completed `.pbix` saved locally, drop it here before pushing to GitHub. GitHub renders `.pbix` as a binary download (no inline preview), so consider also exporting each report page as a PNG into `../assets/screenshots/` — those *do* render inline in the README and are what most recruiters actually look at.
